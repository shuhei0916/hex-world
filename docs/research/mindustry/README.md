# Mindustry 調査メモ

`generated/` にゲームのデータから作った一覧がある（git には入れない）。

```
J="X:/SteamLibrary/steamapps/common/Mindustry/jre/desktop.jar"
javac -cp "$J" -d <classes> tools/research/MindustryDump.java
java -cp "$J;<classes>" MindustryDump mindustry.json
python -I tools/research/mindustry.py mindustry.json "$J" docs/research/mindustry/generated
```

## 情報源

- ゲーム本体（`jre/desktop.jar`）のコンテンツ読み込み処理を `MindustryDump.java` から呼び出し、JSON に書き出した。
  - アイテム・液体・ブロック・研究ツリーが入っている。
  - ユーザーの設定やセーブには触れない。
- 日本語名は jar の中の `bundles/bundle_ja.properties`。

## データから読み取れる構造

### 1. 加工はとても浅い。素材は「建てるため」にある

- 加工の段階は最大 2（サージ合金・爆発性化合物・酸化物）。
- 加工ブロックは 27 種しかない。
- 素材の主な使い道は加工の材料ではなく、ブロックの建設コスト。
  - シリコンは 126 種、黒鉛は 74 種のブロックの建設に使われる。
- 遊びの中心は生産の深さではなく、タワーディフェンスと物流の配置。

### 2. 研究ツリーはブロックごとの 1 本の木で、コストはコアに貯めた資源

- 1 ノード = 1 ブロック（またはユニット・アイテム・セクター）。親を研究すると子が開く、単純な木。
- コストは建設コストの何十倍もの資源。
  - 例：コア: ファンデーションは銅 10,000・鉛 10,000・シリコン 6,400。
  - 各ステージで掘ってコアに送った資源を使う。
- 深さはセルプロ 10、エレキル 14。

### 3. 研究に「セクターの攻略」が条件として付く

- 条件は「攻略: ○○」が 109 件、「到達」が 60 件、「生産: ○○」が 38 件。
- 研究を工場の出力だけで進めさせず、マップ（戦闘）を進めることと組み合わせている。
- ツリーにはセクター自体もノードとして入っていて（セルプロ 29 件）、研究と攻略の順番が 1 つの木にまとまっている。

# shapez.io 調査メモ

`generated/` にソースから作った一覧がある（git には入れない）。

```
git clone --depth 1 https://github.com/tobspr-games/shapez.io.git <repo>
python -I tools/research/shapez.py <repo> docs/research/shapez/generated
```

PyYAML が要る（`pip install pyyaml`）。

## 情報源

- 公式リポジトリ（https://github.com/tobspr-games/shapez.io 、GPL-3.0）の JS ソース
  - JS は実行せず、定義の書かれたファイルを正規表現で読んでいる。
- 読んだファイル
  - `src/js/game/modes/levels.js`：レベル
  - `src/js/game/modes/regular.js`：アップグレード
  - `src/js/game/tutorial_goals_mappings.js`：報酬と建物の対応
  - `src/js/core/config.js`：建物の速さ
  - `src/js/game/map_chunk.js`：鉱床の出方
- 日本語名は `translations/base-ja.yaml`。
- 対象は標準版（Steam 版）の値。デモ版はレベルが 8 段で、納品数も違う。

## データから読み取れる構造

### 1. レシピがなく、機械 = 工程

- アイテムは「4 つの象限 × 最大 4 層 × 形 4 種 × 色 8 色」の組み合わせで、レシピ表がない。
- 機械はどれも 1 つの操作だけをする。
  - 切断・回転・着色・混色・積み重ねの 5 つ。
  - 入力は多くても 2 つ（着色機 = 形 + 色、積層機 = 下 + 上、混色機 = 色 + 色）。
- 作り方は、ゴールの形から逆算して工程を並べることで決まる。
- hex-world の「機械を見ればどんな加工か分かる」と同じ考え方を、いちばん突き詰めた形。
- 段階の見積もりは最大 8（Lv21・22・24・26）。

### 2. レベル = 関所で、量も同時に求める

- 26 段で、ほぼ 1 段ごとに建物か変種を 1 つ解放する（報酬なしは Lv2 だけ）。
- 納品数は 30 から 50,000 まで伸びる。
  - Lv12 までは 1 段で 1.0〜2.4 倍とゆるやか。
  - Lv13 から 3,800 → 10,000 → 20,000 と跳ね、終盤は 25,000 で横ばいになる。
- 序盤は 1 段ごとに機械が 1 つ増え、その機械の使い方を 1 つの形で教える。
  - Lv1 切断機 → Lv2 半分の円、Lv4 回転機 → Lv5・6 は回転が要る形。
  - チュートリアルとレベルが同じ物になっている。

### 3. アップグレードは「前に作った形」を払う

- 4 系統（ベルト・抽出・切断回転積み重ね・混色着色）× 7 段。8 段目からは無限強化（約 1,000 段）。
- 値段の形は、どれも過去のレベルの形。
  - 例：ベルト 3 段目の `CpCpCpCp` は Lv9 の形。
- 前の段で払った形も 2.5 倍にして次の段に足すので、昔のラインを止められない。
  - ベルト 5 段目は 5 種類で合計 54,100 個。
- レベルのために作ったラインが、そのあとも強化の材料を作り続ける。工場が捨てられず育っていく仕組み。
- 強化は機械 1 台ずつではなく、系統ごとに全体へ効く。
  - hex-world の「コンベア速度・採掘速度の研究」と同じ形。

### 4. 機械の速さの差が、そのまま比率のパズル

- 強化前の処理速度（ベルト 1 本 = 2 個/秒）
  - 回転機 2、切断機 0.5、混色機 0.4、着色機 0.33、積層機 0.25 個/秒
- ベルト 1 本を満たすには、積層機なら 8 台、回転機なら 1 台が要る。
- どこが詰まるかは「機械の速さ ÷ ベルトの速さ」で決まり、数字で読める。
- Lv14 だけは「毎秒 8 個を流し続ける」という速さの目標になっている。
  - 総数ではなく、ラインの太さそのものを課題にする珍しい形。

### 5. 遠くへ行くほど、新しい素材と混ざった鉱床が出る

- 星と風車の鉱床は、原点から 7 chunk 以上離れないと出ない。
- 1 つの鉱床に 2 種の形が混ざるのは 10 chunk から、4 種がばらばらなのは 15 chunk から。
- 青の鉱床は 3 chunk 目から。
- 序盤の 4 chunk（原点の周り）は、赤・緑・円・四角に固定されている。
- 探索の報酬が「遠くにしかない原料」になっている。
  - hex-world の「未踏 chunk を戦って解放」で新しい原料を手に入れる流れと、同じつなぎ方。

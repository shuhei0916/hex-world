# Nova Lands 調査メモ

hex-world の参考にするため、Nova Lands の研究・アイテム・建物・進行要素を集めて分析したもの。
名前や構成をそのまま写すためではなく、構造とペースの付け方を学ぶための資料。

## 一覧表（generated/）

`generated/` にゲームのデータから作った一覧がある（ゲームの内容そのものなので git には入れない）。

| ファイル | 中身 |
|---|---|
| `items.md` | アイテム 116 件を加工の段階ごとに（英語名・日本語名・作る場所・説明） |
| `recipes.md` | レシピを建物ごとに（入力・出力・時間・毎分の出力） |
| `buildings.md` | 建物（コスト・電力・速度・レシピ数・説明） |
| `progression.md` | 研究 39 件・島 17 件・チャレンジ 45 件・実績など（名前と説明のみ） |
| `stats.md` | 段階ごとの件数、レシピの入力数、よく材料になるアイテム |

作り直し方:

```
# 1. NovaCalc のデータを取ってくる（どこか作業用のフォルダへ）
curl -o gamedata.json https://raw.githubusercontent.com/frostmx/novacalc/main/data/gamedata.json
# 2. 一覧を生成
python -I tools/research/nova_lands.py gamedata.json "X:/SteamLibrary/steamapps/common/Nova Lands" docs/research/nova_lands/generated
```

## 情報源

- **NovaCalc**（https://github.com/frostmx/novacalc）の `data/gamedata.json`
  - 有志の生産計算機。ゲームファイル（Unity IL2CPP）から抜き出したアイテム・レシピ・建物の数値。2026-10 時点で更新中。
  - ライセンス表記なし。手元の参考にだけ使い、再配布はしない。
- **ゲーム内のローカライズ**（`Nova Lands_Data/StreamingAssets/Localization/messages_{en,ja}.bytes`）
  - 中身はただの JSON。英語名・日本語名・説明文はここから取った。研究・チャレンジ・島の名前もここにある。
- Fandom の wiki（nova-lands.fandom.com）は自動取得を拒否されて（HTTP 402）読めなかった。

## まだ取れていないもの

- **研究ツリーの中身**（前提・コスト・解放するもの）
  - ゲームのアセットに `ResearchDescriptor` として入っている。
  - NovaCalc の `tools/extract_game.py` を手元のゲームに対して動かせば抜き出せる見込み（UnityPy と TypeTreeGeneratorAPI が必要）。
- **島の解放コスト**
  - バイオームスキャナーのレシピに一部ある（例：スチール 2 + プラスチール 2）が、どの島に対応するかは不明。

## データから読み取れる構造

### 1. 裾野が広く、上は一本の幹になっている

- 段階 0〜3 に 116 件中 78 件が集まっている。
- 段階 5 以上はほぼ 1 段 1〜3 件で、最終段階は 15。
- 終盤は次のように一本道で進む。

  > 強化スーパーメタル → ベヘムチウム電池 → ハイパーコンピューター → 量子コンピューター → 中性子核 → ブラックホール → 暗黒物質

- 序盤は横に広く遊ばせ、終盤は「次はこれ」が明確な縦の道になっている。

### 2. レシピは単純

- 167 件のうち、入力 1〜2 種が 136 件。3 種は 22 件だけで、4 種以上はない。
- 難しさは「混ぜる種類の多さ」ではなく「段の深さ」と「量」から来ている。
- hex-world の「工学寄りにしない」と相性がよい。

### 3. 時間がほぼ倍々で伸びる

- 上位のレシピ時間は 72s の 2 のべき乗倍になっている。
  - 精製：1m12s → 2m24s → 4m48s
  - 組み立て：9m36s → 19m12s → 38m24s
- 上位ほど 1 個に時間がかかる。そのため上の段ほど同じ建物を何台も並べる必要があり、工場が自然に大きくなる。
- 建物の速度は多くが 0.8 で、潤滑油・スキル・宝石で上げる。

### 4. 規模の拡大は「梱包による圧縮」でまかなう

- Packager で 100 個を 1 梱包にまとめる。巨大炉（MEGA FURNACE）は梱包を入力にして 150 個単位で作る。
- 例：鉄インゴットは、炉 1.25/分に対して巨大炉 11.25/分（9 倍）。
- コンベアや建物を増やす代わりに「圧縮した荷物を扱う上位の建物」で規模を上げる。
- hex-world のチェスト輸送（chunk → バイオーム → planet）の上位互換の考え方に近い。

### 5. 出口（消費するだけの施設）が目標になっている

- **Nova ゲートウェイ**：アイテムを納めるだけの配送ミッション。チャレンジ「最終ミッション」の条件。
- **バイオームスキャナー**：アイテムを消費して島を解放する。探索が生産で区切られている。
- **ブラックホールピラミッド**：最終盤の納品先。

### 6. チャレンジ 45 件が「次に作る中間素材」の道しるべ

- 「鉄インゴットを N 個」「ガラスを N 個」「プラスチールを N 個」「初めてのスーパーコンピュータ」のように、主要な中間素材ごとに目標がある。
- 研究とは別に、生産の順番を自然に案内している。

### 7. 生き物・農業が本線に組み込まれている

- プラスチールは「スチール + プラスチック + 動物の鱗」で作る。動物の鱗はスコーティカ（生き物）から取れる。
- 植物（小枝・コルニリアの花・ジュースボールなど）は段階 0 の主要な材料で、よく材料に使われるアイテムの上位に多い。
- 探索・牧畜を、工場の本線から外せない形で結びつけている。

### 8. 手作りと自動生産の分担

- 作業台は全レシピ 2 秒で、ボット・装備・回復アイテムなど「プレイヤーが使う物」を作る。
- 生産設備は工場用の素材を作る。役割がはっきり分かれている。

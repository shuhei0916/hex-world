# Factorio 調査メモ

`generated/` にゲームのデータから作った一覧がある（git には入れない）。対象は 2.1.24 の本体のみ（Space Age は入っていない）。

```
"X:/SteamLibrary/steamapps/common/Factorio/bin/x64/factorio.exe" --dump-data
python -I tools/research/factorio.py "$APPDATA/Factorio/script-output/data-raw-dump.json" "X:/SteamLibrary/steamapps/common/Factorio" docs/research/factorio/generated
```

## 情報源

- `factorio.exe --dump-data` が書き出す公式のプロトタイプ（data.raw）
  - レシピ・研究・機械が全部入っている。
- 日本語名は `data/base/locale/ja/base.cfg`。

## 一覧表（generated/）

| ファイル | 中身 |
|---|---|
| `items.md` | アイテムを加工の段階ごとに |
| `recipes.md` | レシピを作る機械の種類（crafting category）ごとに |
| `buildings.md` | 組立機・炉・採掘機・研究所（速度・電力・モジュール枠） |
| `research.md` | 研究 196 件（前提・コスト・解放するレシピ・効果） |
| `stats.md` | 段階・入力数・材料の使われ方・研究の深さ |

## データから読み取れる構造

### 1. 段は浅く、中間が分厚い

- 作れるアイテムの段階は最大 8。そのうち 3〜6 段に約 150 件が集まっている。
- 鋼材・電子基板・鉄板・歯車の 4 つは、それぞれ 40〜60 のレシピで材料になる。
  - 少数の中間素材を大量に、あちこちへ配る構造で、物流の設計がゲームの中心になる。
- 入力 3 種のレシピが一番多く（81 件）、4 種以上も 26 件ある。
  - 5 本の中で一番「混ぜる」ゲームで、工学寄りの難しさはここから来ている。

### 2. 研究は深い木で、コストは「サイエンスパックの種類」で段が分かれる

- 研究 196 件、深さは最大 19。
- コストは「回数 × 使うパックの組 × 1 回の秒数」。
  - 回数の中央値は 200、最大 5,000。上限なしで続く研究も 9 件ある。
- 使うパックが 1 種 → 7 種と増えるごとに、新しい生産ラインを作る必要がある。
  - パック自体が「次の段の工場を作れ」という課題になっている。
- 研究は研究所で、自動で流し込んだパックを消費して進む。研究そのものが工場の出力先になる。

### 3. 最初の数件は「きっかけ」で解放される

- 蒸気発電は「鉄板を 50 枚作る」、電子工学は「銅板を 10 枚作る」で解放される。
  - 研究所を建てる前の導入を、作業そのものを条件にして進める。
- 石油処理・ウラン処理も「その資源を掘る」がきっかけになっている。

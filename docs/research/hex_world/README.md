# hex-world の集計

他の自動化ゲームと同じ物差しで、hex-world のデータを測る。データを足したら作り直して、形を比べる。

```
tools/research/hex_world.sh
```

- ヘッドレスの Godot が `GameDataExport.to_dict()` を JSON に書き出す（`tools/scenarios/export_game_data.gd`）。
- `tools/research/hex_world.py` がそれを集計する。
- `generated/` は作り直すたびに変わるので、git には入れない。

## 一覧表（generated/）

| ファイル | 中身 |
|---|---|
| `items.md` | アイテムを段階ごとに（作る機械・要るバイオーム・使い道） |
| `recipes.md` | 機械ごとのレシピ（秒・出力/分） |
| `progression.md` | ハブの目標・各レベルで開く研究・研究の一覧・設置コスト |
| `stats.md` | 他のゲームと同じ物差しの数字・段階・入力数・バイオーム数・使い道のないアイテム |

## 2026-11-18 時点（作り直す前）

| | hex-world | 近い例 |
|---|---|---|
| 素材（原料 + 加工品） | 20（4 + 16） | Mindustry 33 |
| レシピ（加工） | 16 | Mindustry 27 |
| 加工の段階の最大 | 7 | Factorio 8、shapez.io 約 8 |
| 入力 3 種以上のレシピ | 0% | shapez.io 0% |
| 研究の件数 / 深さ | 7 / 3 | — |
| ハブの目標 | 12 段 | shapez.io 26 段 |

### 読み取れること

- **段は深いが、どの段も細い。** 段階 1〜4 に 3〜4 件ずつ、5〜7 段目は 1 件ずつの一本道。
  - Nova Lands や Captain of Industry の上の方と同じ形が、最初から始まっている。
- **研究が進行にほとんど関わらない。**
  - 7 件のうち 4 件は速度の強化、3 件はチェスト。
  - Lv7 と Lv9〜12 では開く研究がない。
  - Lv5〜12 の目標には報酬がない（shapez.io では報酬なしは 26 段のうち 1 段だけ）。
- **目標の段階が行ったり来たりする。** Lv8 で段階 5 のモーターを納めたあと、Lv9 で段階 1 のガラスに戻る。
  - shapez.io は、レベルごとに 1 工程ずつ増える。
- **バイオームを混ぜるのは段階 2 から。** 4 つすべてが要るのは探査機だけ。
- **使い道のないアイテムはない。**
  - ただし鋼の梁・骨組み・レンズ・原料の 3 種（銅鉱石・石炭・砂）は「材料」にしか使われない。

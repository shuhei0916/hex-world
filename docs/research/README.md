# 自動化ゲームの調査

hex-world の参考にするため、自動化ゲーム 6 本の研究・アイテム・レシピ・建物を集めて比べたもの。
名前や構成を写すためではなく、構造とペースの付け方を学ぶための資料。

- 各ゲームの詳細は `<ゲーム>/README.md`
- 一覧表は `<ゲーム>/generated/`（ゲームの内容そのものなので git に入れない。作り直し方は各 README にある）
- 生成スクリプトは `tools/research/`

## 比べて見えること

### 「難しさ」をどこに置くか

- **Factorio**
  - 入力 3 種以上が半分を超える。少数の中間素材をあちこちへ配る物流の設計が難しさの中心。
  - hex-world の「工学寄りにしない」と一番遠い。
- **Nova Lands・Mindustry**
  - 入力はほぼ 1〜2 種。
  - Nova Lands は段の深さと量、Mindustry は配置と防衛で難しさを出す。
- **Satisfactory**
  - その中間。入力 4 種のレシピもあるが、段階はピラミッド状で見通しがよい。
- **shapez.io**
  - レシピ表がなく、1 つの操作だけをする機械を並べる。難しさは「機械の速さの差」から来る比率のパズル。
  - 機械の速さが数字で読めるので、どこが詰まるかが分かりやすい。hex-world の「ボトルネックを分かりやすく」に一番近い。

### 研究の役割は大きく 2 通り

- **関所型**（Nova Lands）
  - 新しい素材を少量作れたら次が開く。研究は進み具合の確認で、量はチャレンジや納品が受け持つ。
- **消費型**（Factorio・Captain of Industry・Satisfactory・Mindustry）
  - 研究そのものが大量の素材を食べる。
  - Factorio と Captain of Industry は研究所に流し込み続ける形で、研究が工場の主な出力先になる。
  - Satisfactory は HUB に数百個、Mindustry はコアに数万個をまとめて納める形。
- **関所と量を 1 つにまとめた形**（shapez.io）
  - レベルは 1 段ごとに機械を 1 つ解放する関所で、納品数も 30 → 50,000 と伸びる。
  - 強化の値段は「過去のレベルの形」で、前の段の分も 2.5 倍で積み増す。昔作ったラインが止まらずに働き続ける。
- hex-world の「研究リスト」（研究で購入）はどちらにも寄せられる。
  - 少量で開く関所型にして、量は目標（納品）に任せる。
  - 研究自体を工場の出力先にする。

### 研究の脇に「探索」をつなぐやり方

- **Mindustry**：研究の条件に「セクターを攻略」を入れ、マップの進行と研究を 1 本の木にまとめている。
  - hex-world の「未踏 chunk を戦って解放」「研究で新しいカードが解放される」とつなぎ方が近い。
- **Satisfactory**：探索で拾ったハードドライブで代替レシピを選ばせ、工場の組み直しを促す。
- **Nova Lands**：島の解放（バイオームスキャナー）に素材を払わせ、探索を生産で区切る。
- **shapez.io**：原点から遠いほど新しい形（星・風車）や、混ざった鉱床が出る。探索の報酬が「遠くにしかない原料」になっている。

### 規模の上げ方

- **Nova Lands**：梱包（100 個を 1 つに）と、梱包を扱う巨大炉で規模を上げる。台数は市場のクレジットで買う。
- **Captain of Industry**：同じ機能の建物に I〜V の上位版を用意する。
- **Satisfactory**：機械は増やさず、オーバークロックと代替レシピで効率を上げる。
- hex-world のチェスト 3 段（chunk → バイオーム → planet）は Nova Lands の圧縮に近い。
  - 「上位のチェストほど遠くへ運べる」に「まとめて運べる」を足す余地がある。

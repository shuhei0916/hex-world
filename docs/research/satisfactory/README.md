# Satisfactory 調査メモ

`generated/` にゲームのデータから作った一覧がある（git には入れない）。

```
python -I tools/research/satisfactory.py "X:/SteamLibrary/steamapps/common/Satisfactory" docs/research/satisfactory/generated
```

## 情報源

- ゲームに同梱された公式データ `CommunityResources/Docs/en-US.json` と `ja.json`（UTF-16 の JSON）
  - アイテム・レシピ・建物・研究（FGSchematic）がすべて入っている。
- **入っていないもの**
  - MAM の木構造（どのノードがどれの先か）
  - 軌道エレベーターのフェーズの納品内容
  - 軌道エレベーターのフェーズが Tier を区切る仕組みは一般に知られた仕様で、Docs にはない。

## データから読み取れる構造

### 1. きれいなピラミッド

- 段階ごとのアイテム数は 26 → 26 → 22 → 21 → 18 → 14 → 7 → 5 → 3 → 1。
  - Nova Lands のように途中で一本道にならず、上に行くほど少しずつ細くなる。
- 標準レシピは 181 件。入力は 1〜2 種が 145 件で、4 種のものも 17 件ある。

### 2. 研究は 3 系統で、払い方と性格がそれぞれ違う

- **マイルストーン（HUB）**
  - 主線。Tier 1〜9 にそれぞれ 3〜5 件ある。
  - 素材を数百個単位で納め、2〜20 分待つと解放される。
  - 1 Tier のコスト合計は 1,700 個（Tier 1）から 20,300 個（Tier 9）まで増える。
  - 研究は「量を作れるようになった」ことの確認として働く。
- **MAM**
  - 脇道。拾ったもの（遺骸・ベリー・キノコ・石英・カテリウムなど）を少量入れて調べる。
  - 探索と結びついている。
- **代替レシピ**
  - 探索でハードドライブを拾うと、候補の中から 1 つ選べる。
  - 代替レシピは 110 件あり、標準 181 件の 6 割ほどの数。
  - 同じ物の別の作り方を「探索の報酬」として渡し、工場の組み直しを促している。

### 3. AWESOME シンクは「余りを捨てる場所」と「第二の通貨」を兼ねる

- 余った物をシンクに入れるとポイントになり、クーポンでショップの品（飾りなど 173 件）と交換できる。
- 余剰の捨て場が、そのまま報酬になる。

### 4. 機械の段は少なく、役割で分ける

- レシピを持つ機械は 11 種。製錬機・製作機・組立機・製造機と、入力の数で段が分かれている。
- 加工の機械には上位版がない（採掘機やベルトにはある）。1 台を速くするのはオーバークロック（パワーシャード）の役目。

# レシピ・研究・目標の設計（案）

2026-11-18 の案。まだ実装していない（今の実装は 2026-11-15 版。そちらは git の履歴にある）。
6 本の自動化ゲームの調査（`docs/research/`）をもとに、原料 4 → 7、加工品 16 → 35 に広げる。
名前や構成は写さず、このゲーム用に組み立て直している。

## 方針

1. **バイオームを混ぜる**: 段階が上がるほど、違うバイオームの資源を組み合わせる（今と同じ）。
2. **比率は単純に**: 材料は 2 種まで、個数は 1〜2 個、出力は 1 種。副産物なし（今と同じ）。液体は入れない。
3. **使い道がはっきりしている**: 作った物は「材料」「設置コスト」「研究」「ハブの目標」のどれかに使う。
4. **機械の役割を分ける**: 機械は届いた材料で自動でレシピを選ぶ。同じ機械のレシピ同士で材料を重ねない。
   - この制約の中で品数を増やすため、機械を 5 種 → 7 種に増やす（Mindustry・shapez.io 式。2026-11-18 合意の A 案）。
5. **本筋の機械はレベルで自動解放、研究は取らなくても進める物**（2026-11-14 の合意どおり）。
   - 研究: 速度の強化・チェスト・戦闘スキル・戦闘の強化・寄り道の機械（化学混合機）。
   - 研究の条件に探索（chunk の数・バイオーム）を使う（Mindustry 式）。
   - 速度の強化の値段には、過去の目標の品を使う（shapez.io 式。昔のラインが働き続ける）。
6. **近い原料は建物の材料、遠い原料は上位部品と戦闘**（6 本に共通するペースの付け方）。

## 機械

| 機械 | 入力 | 役割 | 解放 |
|---|---|---|---|
| Miner（採掘機） | なし | 足元の鉱床を掘る | 最初から |
| Smelter（精錬炉） | 1 種 | 熱で溶かす: 鉱石 → インゴット、砂 → ガラス、鋼 → 装甲板 | Lv1 の報酬 |
| Cutter（成形機） | 1 種 | 1 つの素材の形を変える: 板・ネジ・線・梁・レンズ・水晶・ウェハー | Lv2 の報酬 |
| Assembler（組立機） | 2 種 | 部品を組み立てる: 歯車・モーター・エンジン・チップ・振動子・航法装置・探査機・基礎 | Lv3 の報酬 |
| Mixer（混合機） | 2 種 | 混ぜる・組み合わせる: 鋼・回路・骨組み・センサー・コンクリート・計算機 | Lv4 の報酬 |
| **Kiln（窯）** 新 | 1 種 | 焼く: 石灰石 → 生石灰、石英 → シリコン、ガラス → 強化ガラス、硫黄 → 固形酸 | Lv7 の報酬 |
| **Chem Mixer（化学混合機）** 新 | 2 種 | 硫黄を使う: 火薬・電池・爆薬・太陽電池・電動ユニット | 研究（火山の chunk を持つ） |

- 窯は探査機までの本筋（シリコン → チップ）に必須なので、レベルで開く。
- 化学混合機で作る物は、どれも戦闘と強化にしか使わないので研究で開く（寄り道）。

## 実装の順番（案）

1. 新しい原料・バイオーム（近い 1 つ）と窯、段階 1〜2 の新アイテム。惑星の生成に石灰岩の台地を足す。
   - **済み（2026-11-18）**: 石灰石・生石灰・コンクリート、窯（Lv7 の報酬、ツールバーのキー 0）、目標に Concrete（Lv8）、Biome チェストの値段をコンクリートに。
   - 強化ガラス（窯）は使い道の太陽電池が 3 番目なので、そのときに足す。レベルの並べ直しは 4 番目でまとめて行う。
2. 遠いバイオーム 2 つ（距離の制限つき）と、結晶の洞窟の系統（シリコン → チップ → 計算機 → 航法装置）。探査機のレシピを変える。
3. 化学混合機と火山の系統、戦闘の研究。新しい効果（最大 HP・最大マナ・倉庫の上限）を足す。
4. 目標・研究・設置コストを表のとおりに付け直す（`tests/unit/utils/test_game_balance.gd` が払えるかを確かめる）。
5. `tools/research/hex_world.sh` で集計し、形を確かめる。
